# Security

Report suspected vulnerabilities in `@glassypic/mcp-server` and the GlassyPic desktop extension privately. Do not open a public GitHub issue for an unfixed vulnerability.

## How to report

1. Preferred: open a private advisory at <https://github.com/onepunchtechnology/glassypic-mcp-server/security/advisories/new>.
2. If that form is unavailable, email `privacy@glassypic.com` with the subject `MCP security report`.

Include the package or `.mcpb` version, the affected tool or file, and a reproduction that does not include access tokens, session files, or other credentials.

## What happens next

We acknowledge the report and investigate it with a reasonable standard of care. We will follow up with the reporter before public disclosure. This channel covers the local MCP server and the desktop extension distributed from this repository.
